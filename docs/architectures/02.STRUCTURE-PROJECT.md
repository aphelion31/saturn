```

├── src/                      Rust backend

│   ├── cycles.rs             cycles and cycle work items

│   ├── views.rs              saved views, intake
│   ├── pages.rs              pages and collaborative editing
│   ├── notifications.rs      notifications, stickies, recent visits, home widgets
│   ├── assets.rs             file uploads (disk storage)
│   └── public.rs             public boards API (/api/public/*)
├── web/                      Plane's pnpm workspace (unchanged apps)
│   ├── apps/web              main app, React Router SPA
│   ├── apps/admin            god-mode, React Router SPA, base /god-mode
│   ├── apps/space            public boards, React Router SPA, base /spaces (SSR turned off)

```

## Where routes live

Each module's `routes()` registers full paths with Plane's trailing slash and is merged in `app()` in
`src/main.rs`. Anything under `/api/` or `/auth/` that no module answers returns 501. Everything else is a
static file or an SPA fallback.

## Environment

| Variable          | Default                       | Purpose                                                       |
| ----------------- | ----------------------------- | ------------------------------------------------------------- |
| `DATABASE_URL`    | `postgres://localhost/saturn` | Postgres connection                                           |
| `BIND`            | `0.0.0.0:3000`                | Listen address                                                |
| `WEB_URL`         | `http://localhost:3000`       | Public origin; used for redirects and the origin check        |
| `SECRET_KEY`      | dev value                     | Signs sessions. Use Plane's value to keep existing sessions   |
| `WEB_DIR`         | `web/apps`                    | Folder holding `<app>/build/client` for web, admin, space     |
| `STORAGE_DIR`     | `storage`                     | Uploaded files                                                |
| `FILE_SIZE_LIMIT` | `5242880`                     | Upload limit in bytes                                         |
| `DB_POOL`         | `10`                          | Max Postgres connections                                      |
| `ENABLE_SIGNUP`   | `0` (instance info), `1` (sign up) | Same meaning as in Plane; `instance_configurations` wins |
| `RUST_LOG`        | `info,tower_http=warn`        | Log level                                                     |
